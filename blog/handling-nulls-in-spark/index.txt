<h2 id="null-is-a-marker-not-a-value">Null Is a Marker, Not a Value<a class="heading-anchor" href="#null-is-a-marker-not-a-value" aria-label="Link to this section">#</a></h2>
<p>Spark treats nulls the way SQL does. Any operation involving a null generally yields null, unless you handle it explicitly.</p>
<p>Three rules explain most null surprises:</p>
<ol>
<li><p><strong>Null propagation</strong>: If you do an arithmetic operation (e.g., <code>colA + colB</code>) and either <code>colA</code> or <code>colB</code> is null, the result is null unless a function handles the null explicitly (like coalesce).</p>
</li>
<li><p><strong>Comparison</strong>: Comparing anything with null, even null itself, gives null, and a filter treats null as &quot;no&quot;. That&#39;s why <code>col(&quot;age&quot;) == None</code> matches nothing. Use <code>isNull()</code> or <code>isNotNull()</code> instead.</p>
</li>
<li><p><strong>Equi-Null safe join</strong>: Spark SQL provides nullSafeEq or eqNullSafe (<code>&lt;=&gt;</code> in SQL) to compare two columns including nulls. This means if both sides are null, it returns true.</p>
</li>
</ol>
<aside class="callout callout-note">
      <p class="callout-title">Note</p>
      <div class="callout-body"><p>In SQL, null is a marker, not a value.</p>
</div>
    </aside>

<h2 id="coalesce-picks-the-first-value-that-exists">coalesce Picks the First Value That Exists<a class="heading-anchor" href="#coalesce-picks-the-first-value-that-exists" aria-label="Link to this section">#</a></h2>
<ul>
<li>In Spark SQL and DataFrame APIs, <code>coalesce()</code> is used to return the first non-null value among its arguments.</li>
<li>If you have multiple columns and want a single column which picks up a non-null value from one of them in order, or you want to replace a single column’s null value with a fallback.</li>
</ul>
<div class="code-block">
      <div class="code-head">

        <button type="button" class="code-copy">Copy</button>
      </div>

<span class="line"><span style="color:#0E1116">              col(</span><span style="color:#032563">"Rotten_Tomatoes_Rating"</span><span style="color:#0E1116">),  </span></span>

<span class="line"><span style="color:#0E1116">              coalesce(col(</span><span style="color:#032563">"Rotten_Tomatoes_Rating"</span><span style="color:#0E1116">), col(</span><span style="color:#032563">"IMDB_Rating"</span><span style="color:#0E1116">) </span><span style="color:#A0111F">*</span><span style="color:#023B95"> 10</span><span style="color:#0E1116">).alias(</span><span style="color:#032563">"Rating"</span><span style="color:#0E1116">))</span></span>

<h2 id="sorting-puts-nulls-first-unless-you-say-otherwise">Sorting Puts Nulls First Unless You Say Otherwise<a class="heading-anchor" href="#sorting-puts-nulls-first-unless-you-say-otherwise" aria-label="Link to this section">#</a></h2>
<p>When you order a DataFrame in Spark, null handling can change your result. By default, Spark sorts <code>nulls first in ascending order</code> and <code>last in descending order</code>.</p>
<ol>
<li><code>asc_nulls_first</code>: Ascending order, placing nulls at the top.</li>
<li><code>asc_nulls_last</code>: Ascending order, placing nulls at the bottom.</li>
<li><code>desc_nulls_first</code>: Descending order, placing nulls at the top.</li>
<li><code>desc_nulls_last</code>: Descending order, placing nulls at the bottom</li>
</ol>
<div class="code-block">
      <div class="code-head">
        <span class="code-lang">Python</span>
        <button type="button" class="code-copy">Copy</button>
      </div>

<span class="line"></span>
<span class="line"><span style="color:#0E1116">move_nulls_to_end </span><span style="color:#A0111F">=</span><span style="color:#0E1116"> df.orderBy(col(</span><span style="color:#032563">"Rotten_Tomatoes_Rating"</span><span style="color:#0E1116">).desc_nulls_last())</span></span>
<span class="line"><span style="color:#0E1116">move_nulls_to_end.show()</span></span></code></pre>

<h2 id="spark-sqls-other-null-functions">Spark SQL&#39;s Other Null Functions<a class="heading-anchor" href="#spark-sqls-other-null-functions" aria-label="Link to this section">#</a></h2>
<ol>
<li><strong>equal_null</strong>: Returns <code>true</code> if both expressions are equal (including both being <code>NULL</code>), else <code>false</code>.  </li>
<li><strong>ifnull</strong>: Returns the second expression if the first is <code>NULL</code>, otherwise returns the first. Same as <code>coalesce</code>. </li>
<li><strong>nvl</strong>: Same as <code>ifnull</code>—substitutes a <code>NULL</code> value with a provided fallback. Same as <code>coalesce</code>.</li>
<li><strong>nullif</strong>: Returns <code>NULL</code> if both expressions match, otherwise returns the first expression.  </li>
<li><strong>nvl2</strong>: Returns the second expression if the first is not <code>NULL</code>, otherwise returns the third.</li>
</ol>

<h2 id="cheat-sheet">Cheat Sheet<a class="heading-anchor" href="#cheat-sheet" aria-label="Link to this section">#</a></h2>
<table>
<thead>
<tr>
<th><strong>Function / Operation</strong></th>
<th><strong>One-Line Explanation</strong></th>
</tr>
</thead>
<tbody><tr>
<td><strong>coalesce(expr1, expr2, …)</strong></td>
<td>Returns the first non-null expression in the list.</td>
</tr>
<tr>
<td><strong>isNull(column)</strong></td>
<td>Checks if the column’s value is null, returning a boolean.</td>
</tr>
<tr>
<td><strong>isNotNull(column)</strong></td>
<td>Checks if the column’s value is not null, returning a boolean.</td>
</tr>
<tr>
<td><strong>eqNullSafe(col1, col2)</strong> or <strong>col1 <code>&lt;=&gt;</code> col2</strong></td>
<td>Returns <code>true</code> if <code>col1</code> equals <code>col2</code> or both are null, otherwise <code>false</code>.</td>
</tr>
<tr>
<td><strong>ifnull(expr1, expr2)</strong></td>
<td>Returns <code>expr2</code> if <code>expr1</code> is null, otherwise returns <code>expr1</code>.</td>
</tr>
<tr>
<td><strong>nvl(expr1, expr2)</strong></td>
<td>Same as <code>ifnull</code>: substitutes <code>expr2</code> when <code>expr1</code> is null.</td>
</tr>
<tr>
<td><strong>nullif(expr1, expr2)</strong></td>
<td>Returns <code>NULL</code> if <code>expr1</code> equals <code>expr2</code>, otherwise returns <code>expr1</code>.</td>
</tr>
<tr>
<td><strong>nvl2(expr1, expr2, expr3)</strong></td>
<td>Returns <code>expr2</code> if <code>expr1</code> is not null, otherwise returns <code>expr3</code>.</td>
</tr>
<tr>
<td><strong>fillna / na.fill(value[, subset])</strong></td>
<td>Replaces null values in specified columns (or all) with a given value.</td>
</tr>
<tr>
<td><strong>dropna / na.drop([how, subset])</strong></td>
<td>Removes rows containing null values (based on any/all columns or a subset).</td>
</tr>
<tr>
<td><strong>asc_nulls_first / asc_nulls_last</strong> (when sorting)</td>
<td>Orders rows ascending, placing nulls either first or last.</td>
</tr>
<tr>
<td><strong>desc_nulls_first / desc_nulls_last</strong> (when sorting)</td>
<td>Orders rows descending, placing nulls either first or last.</td>
</tr>
</tbody></table>
