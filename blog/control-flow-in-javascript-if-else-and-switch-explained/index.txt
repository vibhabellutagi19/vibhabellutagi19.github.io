21:Tbfeb,<p>Your music app skips explicit songs when parental controls are on. Your bank app blocks a payment when your balance is too low. Your favorite game says &quot;Game Over&quot; the moment your health hits zero.</p>
<p>None of these apps runs the same code every time. They check something first, then decide what to do.</p>
<blockquote>
<p>Every decision a program makes comes down to a handful of statements: <code>if</code>, <code>else</code> and <code>switch</code>.</p>
</blockquote>
<p>This post covers each of them with step-by-step examples, the one <code>switch</code> mistake that causes real bugs, and a simple rule for choosing between <code>switch</code> and <code>if-else</code>.</p>
<hr>
<h2 id="1-code-runs-top-to-bottom-until-you-branch">1. Code Runs Top to Bottom, Until You Branch<a class="heading-anchor" href="#1-code-runs-top-to-bottom-until-you-branch" aria-label="Link to this section">#</a></h2>
<p>Imagine you&#39;re getting ready in the morning. You don&#39;t just blindly follow the same routine every day — you <em>make decisions</em>:</p>
<ul>
<li><p><strong>If</strong> it&#39;s raining, grab an umbrella.</p>
</li>
<li><p><strong>Otherwise</strong>, leave it at home.</p>
</li>
<li><p><strong>If</strong> you&#39;re running late, skip breakfast.</p>
</li>
</ul>
<p>This is exactly what control flow means in programming. By default, JavaScript reads and executes your code <strong>line by line, top to bottom</strong>. But with control flow statements, you can tell JavaScript:</p>
<blockquote>
<p><em>&quot;Don&#39;t just run everything blindly — check a condition first, then decide what to do.&quot;</em></p>
</blockquote>
<p>Control flow lets your program <strong>branch</strong> into different paths based on conditions. The three main tools for this in JavaScript are:</p>
<ul>
<li><p><code>if</code> statements</p>
</li>
<li><p><code>if-else</code> and <code>else if</code> ladders</p>
</li>
<li><p><code>switch</code> statements</p>
</li>
</ul>
<p>Let&#39;s explore each one.</p>
<hr>
<h2 id="2-if-runs-code-only-when-a-condition-is-true">2. <code>if</code> Runs Code Only When a Condition Is True<a class="heading-anchor" href="#2-if-runs-code-only-when-a-condition-is-true" aria-label="Link to this section">#</a></h2>
<p>The <code>if</code> statement is the simplest form of decision-making. It says: <strong>&quot;Only run this block of code IF the condition is true.&quot;</strong></p>
<h3 id="syntax">Syntax<a class="heading-anchor" href="#syntax" aria-label="Link to this section">#</a></h3>
<div class="code-block">
      <div class="code-head">
        <span class="code-lang">JavaScript</span>
        <button type="button" class="code-copy">Copy</button>
      </div>
      <pre class="shiki github-light-high-contrast" tabindex="0"><code><span class="line"><span style="color:#A0111F">if</span><span style="color:#0E1116"> (condition) {</span></span>
<span class="line"><span style="color:#66707B">  // code to run if condition is true</span></span>
<span class="line"><span style="color:#0E1116">}</span></span></code></pre>
    </div><p>If the condition is <code>false</code>, JavaScript simply skips the block entirely and moves on.</p>
<h3 id="real-life-example-checking-age-for-voting">Real-Life Example: Checking Age for Voting<a class="heading-anchor" href="#real-life-example-checking-age-for-voting" aria-label="Link to this section">#</a></h3>
<div class="code-block">
      <div class="code-head">
        <span class="code-lang">JavaScript</span>
        <button type="button" class="code-copy">Copy</button>
      </div>
      <pre class="shiki github-light-high-contrast" tabindex="0"><code><span class="line"><span style="color:#A0111F">let</span><span style="color:#0E1116"> age </span><span style="color:#A0111F">=</span><span style="color:#023B95"> 20</span><span style="color:#0E1116">;</span></span>
<span class="line"></span>
<span class="line"><span style="color:#A0111F">if</span><span style="color:#0E1116"> (age </span><span style="color:#A0111F">>=</span><span style="color:#023B95"> 18</span><span style="color:#0E1116">) {</span></span>
<span class="line"><span style="color:#0E1116">  console.</span><span style="color:#622CBC">log</span><span style="color:#0E1116">(</span><span style="color:#032563">"You are eligible to vote."</span><span style="color:#0E1116">);</span></span>
<span class="line"><span style="color:#0E1116">}</span></span>
<span class="line"></span>
<span class="line"><span style="color:#66707B">// Output: You are eligible to vote.</span></span></code></pre>
    </div><p><strong>Step-by-step walkthrough:</strong></p>
<ol>
<li><p>JavaScript reads <code>age &gt;= 18</code></p>
</li>
<li><p>It checks: is <code>20 &gt;= 18</code>? → <strong>Yes, true</strong></p>
</li>
<li><p>So it enters the block and prints the message</p>
</li>
</ol>
<p>Now try with a different value:</p>
<div class="code-block">
      <div class="code-head">
        <span class="code-lang">JavaScript</span>
        <button type="button" class="code-copy">Copy</button>
      </div>
      <pre class="shiki github-light-high-contrast" tabindex="0"><code><span class="line"><span style="color:#A0111F">let</span><span style="color:#0E1116"> age </span><span style="color:#A0111F">=</span><span style="color:#023B95"> 15</span><span style="color:#0E1116">;</span></span>
<span class="line"></span>
<span class="line"><span style="color:#A0111F">if</span><span style="color:#0E1116"> (age </span><span style="color:#A0111F">>=</span><span style="color:#023B95"> 18</span><span style="color:#0E1116">) {</span></span>
<span class="line"><span style="color:#0E1116">  console.</span><span style="color:#622CBC">log</span><span style="color:#0E1116">(</span><span style="color:#032563">"You are eligible to vote."</span><span style="color:#0E1116">);</span></span>
<span class="line"><span style="color:#0E1116">}</span></span>
<span class="line"></span>
<span class="line"><span style="color:#66707B">// No output — the block is skipped</span></span></code></pre>
    </div><p>Since <code>15 &gt;= 18</code> is <code>false</code>, JavaScript quietly skips the entire <code>if</code> block. Nothing happens.</p>
<h3 id="key-takeaway">Key Takeaway<a class="heading-anchor" href="#key-takeaway" aria-label="Link to this section">#</a></h3>
<blockquote>
<p>Use <code>if</code> when you only care about what happens <strong>when the condition is true</strong>, and want to do nothing otherwise.</p>
</blockquote>
<hr>
<h2 id="3-if-else-always-picks-one-of-two-paths">3. <code>if-else</code> Always Picks One of Two Paths<a class="heading-anchor" href="#3-if-else-always-picks-one-of-two-paths" aria-label="Link to this section">#</a></h2>
<p>What if you want to handle <strong>both</strong> cases — when the condition is true <em>and</em> when it&#39;s false? That&#39;s where <code>else</code> comes in.</p>
<h3 id="syntax-1">Syntax<a class="heading-anchor" href="#syntax-1" aria-label="Link to this section">#</a></h3>
<div class="code-block">
      <div class="code-head">
        <span class="code-lang">JavaScript</span>

<h2 id="4-else-if-checks-conditions-top-to-bottom-and-stops-at-the-first-match">4. <code>else if</code> Checks Conditions Top to Bottom and Stops at the First Match<a class="heading-anchor" href="#4-else-if-checks-conditions-top-to-bottom-and-stops-at-the-first-match" aria-label="Link to this section">#</a></h2>
<p>Real life rarely gives us just two choices. What if you need to check <strong>multiple conditions</strong> in sequence? That&#39;s where <code>else if</code> comes in — it lets you build a <strong>ladder</strong> of conditions.</p>

<div class="code-block">
      <div class="code-head">

<span class="line"><span style="color:#66707B">  // runs if condition1 is true</span></span>
<span class="line"><span style="color:#0E1116">} </span><span style="color:#A0111F">else</span><span style="color:#A0111F"> if</span><span style="color:#0E1116"> (condition2) {</span></span>

</blockquote>

<h2 id="5-switch-matches-one-value-against-many">5. <code>switch</code> Matches One Value Against Many<a class="heading-anchor" href="#5-switch-matches-one-value-against-many" aria-label="Link to this section">#</a></h2>

<h3 id="forget-break-and-every-case-below-runs-too">🔴 Forget <code>break</code> and Every Case Below Runs Too<a class="heading-anchor" href="#forget-break-and-every-case-below-runs-too" aria-label="Link to this section">#</a></h3>
<p>The <code>break</code> keyword tells JavaScript: <strong>&quot;You&#39;re done. Exit the switch now.&quot;</strong></p>
<p>What happens if you forget it? JavaScript will <strong>fall through</strong> — it keeps running every case below the matched one, even if they don&#39;t match. This is called <strong>fallthrough behavior</strong> and is a common source of bugs.</p>
<div class="code-block">
      <div class="code-head">
        <span class="code-lang">JavaScript</span>
        <button type="button" class="code-copy">Copy</button>
      </div>
      <pre class="shiki github-light-high-contrast" tabindex="0"><code><span class="line"><span style="color:#A0111F">let</span><span style="color:#0E1116"> day </span><span style="color:#A0111F">=</span><span style="color:#023B95"> 3</span><span style="color:#0E1116">;</span></span>
<span class="line"></span>
<span class="line"><span style="color:#A0111F">switch</span><span style="color:#0E1116"> (day) {</span></span>
<span class="line"><span style="color:#A0111F">  case</span><span style="color:#023B95"> 3</span><span style="color:#0E1116">:</span></span>
<span class="line"><span style="color:#0E1116">    console.</span><span style="color:#622CBC">log</span><span style="color:#0E1116">(</span><span style="color:#032563">"Wednesday"</span><span style="color:#0E1116">);</span></span>
<span class="line"><span style="color:#66707B">    // ⚠️ No break here!</span></span>
<span class="line"><span style="color:#A0111F">  case</span><span style="color:#023B95"> 4</span><span style="color:#0E1116">:</span></span>
<span class="line"><span style="color:#0E1116">    console.</span><span style="color:#622CBC">log</span><span style="color:#0E1116">(</span><span style="color:#032563">"Thursday"</span><span style="color:#0E1116">);</span></span>
<span class="line"><span style="color:#66707B">    // ⚠️ No break here!</span></span>
<span class="line"><span style="color:#A0111F">  case</span><span style="color:#023B95"> 5</span><span style="color:#0E1116">:</span></span>
<span class="line"><span style="color:#0E1116">    console.</span><span style="color:#622CBC">log</span><span style="color:#0E1116">(</span><span style="color:#032563">"Friday"</span><span style="color:#0E1116">);</span></span>
<span class="line"><span style="color:#A0111F">    break</span><span style="color:#0E1116">;</span></span>
<span class="line"><span style="color:#0E1116">}</span></span>
<span class="line"></span>

    </div><p>Even though <code>day</code> is <code>3</code>, all three cases ran because there was no <code>break</code> to stop the flow. <strong>Always add</strong> <code>break</code> unless you deliberately want fallthrough.</p>
<h3 id="using-fallthrough-intentionally">Using Fallthrough Intentionally<a class="heading-anchor" href="#using-fallthrough-intentionally" aria-label="Link to this section">#</a></h3>

<div class="code-block">
      <div class="code-head">
        <span class="code-lang">JavaScript</span>
        <button type="button" class="code-copy">Copy</button>
      </div>
      <pre class="shiki github-light-high-contrast" tabindex="0"><code><span class="line"><span style="color:#A0111F">let</span><span style="color:#0E1116"> day </span><span style="color:#A0111F">=</span><span style="color:#032563"> "Saturday"</span><span style="color:#0E1116">;</span></span>
<span class="line"></span>
<span class="line"><span style="color:#A0111F">switch</span><span style="color:#0E1116"> (day) {</span></span>
<span class="line"><span style="color:#A0111F">  case</span><span style="color:#032563"> "Saturday"</span><span style="color:#0E1116">:</span></span>

<span class="line"><span style="color:#0E1116">    console.</span><span style="color:#622CBC">log</span><span style="color:#0E1116">(</span><span style="color:#032563">"It's the weekend! 🎉"</span><span style="color:#0E1116">);</span></span>
<span class="line"><span style="color:#A0111F">    break</span><span style="color:#0E1116">;</span></span>
<span class="line"><span style="color:#A0111F">  case</span><span style="color:#032563"> "Monday"</span><span style="color:#0E1116">:</span></span>
<span class="line"><span style="color:#A0111F">  case</span><span style="color:#032563"> "Tuesday"</span><span style="color:#0E1116">:</span></span>
<span class="line"><span style="color:#A0111F">  case</span><span style="color:#032563"> "Wednesday"</span><span style="color:#0E1116">:</span></span>
<span class="line"><span style="color:#A0111F">  case</span><span style="color:#032563"> "Thursday"</span><span style="color:#0E1116">:</span></span>
<span class="line"><span style="color:#A0111F">  case</span><span style="color:#032563"> "Friday"</span><span style="color:#0E1116">:</span></span>
<span class="line"><span style="color:#0E1116">    console.</span><span style="color:#622CBC">log</span><span style="color:#0E1116">(</span><span style="color:#032563">"It's a weekday. 💼"</span><span style="color:#0E1116">);</span></span>
<span class="line"><span style="color:#A0111F">    break</span><span style="color:#0E1116">;</span></span>
<span class="line"><span style="color:#A0111F">  default</span><span style="color:#0E1116">:</span></span>
<span class="line"><span style="color:#0E1116">    console.</span><span style="color:#622CBC">log</span><span style="color:#0E1116">(</span><span style="color:#032563">"Unknown day"</span><span style="color:#0E1116">);</span></span>

<span class="line"></span>
<span class="line"><span style="color:#66707B">// Output: It's the weekend! 🎉</span></span></code></pre>
    </div><p>Here, both <code>&quot;Saturday&quot;</code> and <code>&quot;Sunday&quot;</code> fall through to the same <code>console.log</code> — this is clean, intentional, and readable.</p>
<h3 id="the-default-case">The <code>default</code> Case<a class="heading-anchor" href="#the-default-case" aria-label="Link to this section">#</a></h3>
<p><code>default</code> is like the <code>else</code> in an <code>if-else</code> — it runs when <strong>no case matches</strong>. It&#39;s optional, but always a good idea to include it.</p>
<div class="code-block">
      <div class="code-head">
        <span class="code-lang">JavaScript</span>
        <button type="button" class="code-copy">Copy</button>

<span class="line"><span style="color:#A0111F">    break</span><span style="color:#0E1116">;</span></span>
<span class="line"><span style="color:#A0111F">  case</span><span style="color:#032563"> "yellow"</span><span style="color:#0E1116">:</span></span>

<span class="line"><span style="color:#A0111F">    break</span><span style="color:#0E1116">;</span></span>

<span class="line"><span style="color:#A0111F">  default</span><span style="color:#0E1116">:</span></span>
<span class="line"><span style="color:#0E1116">    console.</span><span style="color:#622CBC">log</span><span style="color:#0E1116">(</span><span style="color:#032563">"Unknown signal — proceed with caution"</span><span style="color:#0E1116">);</span></span>

    </div><h3 id="key-takeaway-3">Key Takeaway<a class="heading-anchor" href="#key-takeaway-3" aria-label="Link to this section">#</a></h3>
<blockquote>
<p>Use <code>switch</code> when you&#39;re matching <strong>one variable</strong> against <strong>multiple exact values</strong>, and each case has a distinct action. Always use <code>break</code> unless you intentionally want fallthrough.</p>
</blockquote>

<h2 id="6-when-to-use-switch-vs-if-else">6. When to Use <code>switch</code> vs <code>if-else</code><a class="heading-anchor" href="#6-when-to-use-switch-vs-if-else" aria-label="Link to this section">#</a></h2>
<p>This is one of the most common questions beginners ask. Here&#39;s a clear breakdown:</p>
<table>
<thead>
<tr>
<th>Scenario</th>
<th>Best Choice</th>
</tr>
</thead>
<tbody><tr>
<td>Checking a range of values (<code>&gt;= 60</code>, <code>&lt; 100</code>)</td>
<td><code>if-else</code></td>
</tr>
<tr>
<td>Checking complex conditions (<code>age &gt; 18 &amp;&amp; hasID</code>)</td>
<td><code>if-else</code></td>
</tr>
<tr>
<td>Matching one variable to many exact values</td>
<td><code>switch</code></td>
</tr>
<tr>
<td>Two possible outcomes</td>
<td><code>if-else</code></td>
</tr>
<tr>
<td>Many named cases (days, months, menu options)</td>
<td><code>switch</code></td>
</tr>
<tr>
<td>Conditions involve different variables</td>
<td><code>if-else</code></td>
</tr>
</tbody></table>

<h3 id="the-golden-rule">The Golden Rule<a class="heading-anchor" href="#the-golden-rule" aria-label="Link to this section">#</a></h3>
<ul>
<li><p>If your conditions involve <strong>ranges, inequalities, or multiple variables</strong> → use <code>if-else</code></p>
</li>
<li><p>If you&#39;re matching <strong>one thing to a list of exact values</strong> → use <code>switch</code></p>
</li>
</ul>

<h2 id="summary">Summary<a class="heading-anchor" href="#summary" aria-label="Link to this section">#</a></h2>
<p>Here&#39;s everything you covered in one quick reference:</p>
<table>
<thead>
<tr>
<th>Statement</th>
<th>Purpose</th>
</tr>
</thead>
<tbody><tr>
<td><code>if</code></td>
<td>Run code only when condition is true</td>
</tr>
<tr>
<td><code>if-else</code></td>
<td>Handle true/false — two outcomes</td>
</tr>
<tr>
<td><code>else if</code></td>
<td>Handle multiple conditions in order</td>
</tr>
<tr>
<td><code>switch</code></td>
<td>Match one value against many exact cases</td>
</tr>
<tr>
<td><code>break</code></td>
<td>Exit the switch block after a match</td>
</tr>
<tr>
<td><code>default</code></td>
<td>Fallback if no case matches</td>
</tr>
</tbody></table>
